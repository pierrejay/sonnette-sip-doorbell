# eda

Hardware design files for the custom RK3506G2 Sonnette board.

Contents:

- `sonnette.epro` — editable EasyEDA Pro project.
- `sonnette_sch.pdf` — exported schematic.
- `sonnette_pcb_3d.png` — 3D render of the assembled PCB.

See [../docs/hardware.md](../docs/hardware.md) for the hardware overview,
BSP notes and board bring-up guide.
