# BSP

Board support package files for the custom RK3506G2 Sonnette board.

This directory contains the device tree and SDK/Buildroot defconfigs that
are copied into the Luckfox Lyra SDK when building the Linux image.

See [../docs/hardware.md](../docs/hardware.md#2-linux-image--bsp) for the
full build, flash, and hardware notes.
